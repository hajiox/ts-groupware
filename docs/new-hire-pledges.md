# 新入社員への誓約書自動送信

承認済みの実TSGアカウントと在籍中の人事台帳が連携した時点を入社手続き完了として記録する。入社手続き完了日時と入社日の遅い方から7日経過後、使用中の「会社機密情報に関する誓約」を未配信の新入社員へ1回だけ送信する。

同じテンプレートの本番誓約が手動配信済み、未提出、処理中、提出済みのいずれかで存在する場合は自動配信しない。仮入社アカウント、未承認・停止・退職者、入社日未登録者、TSG君は対象外。毎日9:05（日本時間）の既存新入社員配信cronが全社員メッセージと誓約書を続けて処理する。

自動配信はテンプレート内容を送信時点で固定し、通常の未提出バナー、7日警告、14日最終警告、本人提出・PDF保存の既存経路を利用する。DBの部分一意制約と保存RPCにより、cron再実行や並行実行でも重複配信しない。
