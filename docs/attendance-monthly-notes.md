# 個人全体の労務士連絡メモ（2026-10-01）

管理 → 勤怠 → 月末勤怠修正・労務士提出で、対象月・所属・スタッフを選び、
「このスタッフ全体のメモ（労務士へ送付）」に入力する。
「変更をまとめて保存」は日別修正と全体メモを保存する。
メモは月・スタッフ別に保存し、日別備考や人事メモとは別に扱う。上限2000文字。
空欄にして保存すると提出資料からメモを取り除ける。

メモ保存時は対象スタッフの提出確認を解除する。内容を再確認してチェックを付ける。
確認解除そのものではメモは消えない。未保存変更がある間の提出・Excel出力は拒否し、
スタッフ・月・所属切替と再読み込みでは破棄を確認する。
他の管理者が保存済みメモを変更した場合は409を返し、入力を残す。

Excelの各個人シートで社員情報の直後に全体メモを出力する。
労務士提出は同じExcel生成経路を使うので添付へ反映する。日別備考は維持する。
メモ読込失敗時は提出ファイルの生成も失敗させ、メモが抜けたまま送信しない。

保存先は `gw_attendance_monthly_notes`。管理権限を持つ勤怠APIとservice_role専用RPCから扱う。
メモ更新と確認解除は同一DBトランザクションで実行する。
マイグレーション: `202610010001_attendance_monthly_notes.sql`。

検証: `pnpm test:attendance-monthly-note-api`、`pnpm test:attendance-monthly-note-export`、
`scripts/test-attendance-monthly-notes.sql`（DBテストは全件ロールバック）、型検査・Lint・build。
労務士への実送信はテストとして行わない。
